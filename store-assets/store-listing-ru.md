# Microsoft Store Listing — Russian

## Product name

SmartWindow

## Short description

Показывает уведомления Windows 11 и сведения о текущем воспроизведении в аккуратном верхнем капсульном интерфейсе.

## Description

SmartWindow — компактная утилита для Windows 11, которая объединяет уведомления и информацию о воспроизводимых медиа в верхней части экрана.

Новое уведомление раскрывается из небольшого круглого индикатора в информационную капсулу, после чего автоматически сворачивается. Во время воспроизведения музыки SmartWindow показывает обложку альбома, название композиции, исполнителя, динамическую волну и кнопки перехода к предыдущей композиции, паузы или продолжения и следующей композиции.

Основные возможности:
• Уведомления в верхней части экрана
• Определение медиасеансов Windows
• Обложка альбома и динамическая волна в цвете обложки
• Предыдущая композиция, пауза или продолжение, следующая композиция
• Прокрутка длинных названий
• Полупрозрачный стеклянный интерфейс
• Объёмное освещение, преломление краёв и световые частицы
• Двусторонняя анимация растворения
• Масштаб окна от 80% до 120%
• Настройка прозрачности консоли
• Запуск вместе с Windows
• Шесть языков интерфейса
• Сочетание Ctrl+M для музыкального режима
• Сочетание Ctrl+M+L для закрепления музыкального окна

SmartWindow обрабатывает уведомления и сведения о медиа локально и не загружает их на серверы Sendyun.
