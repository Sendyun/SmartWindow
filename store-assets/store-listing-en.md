# Microsoft Store Listing — English (United States)

## Product name

SmartWindow

## Short description

Bring Windows 10/11 notifications and current media into a polished top-screen capsule with glass effects, animated particles, and playback controls.

## Description

SmartWindow is a compact Windows 10 and Windows 11 utility that reorganizes notifications and media information around the top center of your screen.

Incoming notifications expand from a subtle circular seed into a clear information capsule, then collapse automatically when they are finished. When media is playing, SmartWindow displays album artwork, title, artist, and an animated waveform with previous, play or pause, and next controls.

Key features:

- Top-screen notification presentation
- Windows media session detection
- Album artwork and accent-colored waveform
- Previous, play or pause, and next controls
- Scrolling support for long titles
- Translucent glass appearance
- Dimensional lighting, edge refraction, and animated particles
- Particle-based close animation
- Window scaling from 80% to 120%
- Console transparency control
- Start with Windows
- Six interface languages
- Ctrl+M music mode shortcut
- Ctrl+M+L music persistence shortcut

SmartWindow processes notification and media information locally. It does not upload notification contents, music metadata, or playback history to Sendyun servers.
