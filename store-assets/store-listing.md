# Microsoft Store Listing Copy

## Product name

SmartWindow

## Display name

智慧窗

## Short description

将 Windows 10/11 通知和正在播放的音乐集中显示在屏幕顶部，并提供透明玻璃、动态粒子、媒体控制与开机自启动。

## Full description

智慧窗是一款面向 Windows 10 与 Windows 11 的顶部通知与音乐控制工具。

收到通知时，智慧窗会在屏幕顶部中央展开轻量胶囊，显示应用名称、消息标题和正文，结束后自动收拢消失。音乐播放时，顶部窗口会显示专辑封面、歌曲、歌手和动态波形，并可展开上一首、暂停或继续、下一首控制。

主要功能：

- 顶部通知展示与自动收拢
- Windows 媒体会话识别
- 专辑封面与主题色动态波形
- 上一首、暂停/继续、下一首
- 长标题循环滚动
- 透明玻璃智慧窗
- 玻璃边缘折射、流光和动态粒子
- 左右双向粒子消失动画
- 80%–120% 窗口尺寸调节
- 控制台透明度调节
- 开机自启动
- 中文、English、日本語、한국어、Русский、Français
- Ctrl+M 音乐模式快捷键
- Ctrl+M+L 音乐窗常驻快捷键

智慧窗在本机处理通知和媒体信息，不上传通知内容、音乐信息或播放历史。
