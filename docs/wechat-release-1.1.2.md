# 从一颗胶囊到桌面伙伴：智慧窗 Ver 1.1.2 正式发布

## 摘要

通知更从容，音乐更贴合。智慧窗从稳定、自由布局到完整日常体验，今天迎来 Ver 1.1.2。

---

有些软件负责占据屏幕，有些软件则希望在恰当的时刻出现，又在完成使命后安静退场。

智慧窗正是后者。

它是面向 Windows 11 的顶部通知与音乐控制工具：系统通知不再从右下角突然弹出，而是从屏幕顶部的一颗圆形种子开始，舒展开成简洁的胶囊，再呈现完整信息。音乐播放时，专辑封面、歌曲信息、动态波形和播放控制也会来到同一个位置。

从 Ver 1.0.1 到今天，智慧窗经历了 5 次版本更新。每一次变化，都来自真实使用中遇到的问题，也来自我们想把桌面体验做得更自然一点的坚持。

## Ver 1.0.1：让第一版真正稳定下来

1.0.1 是智慧窗开始走向长期使用的起点。

这一版本加入了开机自启动、GitHub 入口和安装程序，修复了通知动画阻塞自动收起、媒体监听异常退出后不恢复、后台进程残留等问题。

同时，我们开始规范版本命名、版权声明和非商业使用规则，并加入左右双向的细砂粒子侵蚀动画。

它让智慧窗不只是一个“能动起来的演示”，而是可以留在电脑里持续使用的应用。

## Ver 1.0.2：从固定顶部走向自由布局

这一版加入了用户期待已久的“智慧窗移动解锁”。

开启后，拖动智慧窗会收拢成圆形；松手时，它会识别最近屏幕边缘并自动吸附。顶部和底部保持横向布局，左右两侧则切换成竖向展开，文字方向仍然保持水平。

我们还加入了防遮挡操作模式，让鼠标可以穿过智慧窗，直接操作下方界面。

与此同时，任务栏避让、拖动后波形停止、通知不自动消失和部分专辑封面缺失等问题也在这一阶段得到修复。

## Ver 1.1.0：成为完整的桌面日常工具

1.1.0 是一次较大规模的体验升级。

性能方面，动画期间继续保持最高 165Hz，而静止或暂停时自动降至 30Hz；窗口绘制改用可复用的原生 DIB 表面，减少 GDI 资源反复创建。启动流程也不再重复写入字体和脚本，第二次启动速度明显提升。

多显示器、DPI、任务栏工作区、屏幕位置和停靠边记忆全部得到完善。全屏游戏、视频和演示模式下，智慧窗会自动隐藏普通通知。

通知系统新增历史记录、应用过滤和 `Ctrl + Alt + N` 快捷入口；音乐系统新增播放进度、点击跳转、系统音量、声音设备入口以及更可靠的专辑封面异步加载。

配置导入、导出、恢复默认、后台健康检查、安全模式和直接打开官方赞赏页面，也都在这一版本完成。

## Ver 1.1.1：新品牌，也更可靠

1.1.1 换用了全新的智慧窗品牌 Logo 和程序图标。

控制台开始在两种品牌状态间切换：

- 白底 Logo 显示“智慧窗”；
- 黑底 Logo 显示“Powered by / Sendyun”。

点击 Logo 可以直接打开 Sendyun 官网。

更重要的是，我们找到了音乐播放期间偶发收不到通知的原因：播放进度更新会错误地取消“音乐窗为通知让位”的收拢动画。修复后，通知不会再停留在队列中。

## Ver 1.1.2：圆角新标识，也是陪伴的第几天

今天的 1.1.2，为智慧窗补上了一份更有温度的细节。

### 全新透明圆角双 Logo

白底与黑底 Logo 都更换为透明圆角正方形版本，并同步应用到程序图标和控制台。

两套 Logo 以约 3.2 秒间隔平滑交叉淡化切换。白底状态展示“智慧窗”，黑底状态展示“Powered by / Sendyun”，品牌文字也会同步淡出、淡入，不再发生重叠。

### 你的安装纪念卡

控制中心和关于作者页面现在都会常驻显示：

> 这是你安装“智慧窗”的第 xx 天

首次安装日期会写入本地设置，后续升级不会清零。

点击这张卡片，可以查看：

- 首次安装日期
- 对应星期
- 已陪伴天数
- 当前版本

中文之外的长语言文案会通过横向循环滚动完整展示，不会因为卡片宽度有限而被截断。

### 通知可靠性继续提升

1.1.2 继续修复音乐播放与通知切换时的状态竞争，避免播放进度更新干扰通知让位动画。

## 智慧窗现在可以做什么

- 将 Windows 11 通知显示到顶部胶囊浮窗
- 识别媒体应用、专辑封面、歌曲与歌手
- 动态波形与专辑主题色
- 上一首、暂停/继续、下一首
- 播放进度、点击跳转、系统音量
- 拖动收拢圆形、四边吸附、位置记忆
- 防遮挡鼠标穿透
- 多显示器、DPI、任务栏避让
- 通知历史与应用过滤
- 全屏与演示模式自动静默
- 透明智慧窗、质感增强与光粒子
- 六语言界面
- 配置导入、导出与恢复默认
- 开机自启动
