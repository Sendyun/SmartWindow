# 智慧窗 Ver 1.3.0 - Microsoft Store 更新文案

## zh-CN

智慧窗 Ver 1.3.0 现已支持 Windows 10 1809 及更高版本。

本次更新针对 Windows 10 完成全量适配：通知接管、音乐与专辑封面、播放控制、计时器、透明玻璃、磨砂背景、光粒子、多窗布局、拖动停靠、任务栏避让和多语言界面均可继续使用。新增系统版本兼容检测，在不受支持的系统上会显示明确提示；媒体监听在系统能力不足时不会再反复启动。

Windows 11 继续保留高刷新率动画与高级视觉效果。本次更新还修复了倒计时关闭后铃声可能继续播放的问题。

## en-US

SmartWindow 1.3.0 now supports Windows 10 version 1809 and later.

This update adds full Windows 10 compatibility for notifications, media artwork and controls, timers, translucent and frosted-glass effects, particle animations, multi-window layouts, docking, taskbar-aware positioning, and all six interface languages. System-version detection now provides a clear message on unsupported devices, and media monitoring no longer enters a restart loop when the required system capability is unavailable.

Windows 11 keeps the high-refresh visual experience. This update also fixes countdown alerts continuing after a timer is closed.

## ru

SmartWindow 1.3.0 теперь поддерживает Windows 10 версии 1809 и новее.

Добавлена полная совместимость с Windows 10 для уведомлений, обложек и управления медиа, таймеров, полупрозрачных и матовых эффектов, анимации частиц, многоконного режима, закрепления, учёта панели задач и всех шести языков интерфейса. Проверка версии системы показывает понятное сообщение на неподдерживаемых устройствах, а мониторинг медиа больше не перезапускается бесконечно при отсутствии нужной возможности системы.

В Windows 11 сохраняются эффекты с высокой частотой обновления. Также исправлена проблема, когда звук таймера продолжал воспроизводиться после закрытия обратного отсчёта.
