# 智慧窗 Ver 1.2.0

Ver 1.2.0 主要更新：

- 新增可同时运行的倒计时和正计时。
- 倒计时支持小时、分钟、秒滚轮选择。
- 支持命名常用倒计时、计次、颜色与铃声自定义。
- 计时器与音乐支持双圆角窗口多窗模式。
- 控制台新增实时 FPS、1% Low、帧时间和异常事件监控。
- 新增真实背景模糊磨砂和可调帧率上限。
- 修复倒计时关闭后铃声未停止的问题。

## 下载

- 安装程序：`SmartWindow-Setup-x64.exe`
- 便携版：`SmartWindow.exe`
- 完整源码：`SmartWindow-1.2.0-Source.zip`
- 默认可替换铃声：`timer-alert.wav`
- 铃声替换说明：`timer-alert说明.txt`
- 公众号发布文案：`公众号发布文案.md`

安装器支持静默安装：

```powershell
.\SmartWindow-Setup-x64.exe /S
```

校验所有发布文件的 SHA-256，请参考 `SHA256SUMS.txt`。

## 系统要求

- Windows 11
- x64
- 无需管理员权限
