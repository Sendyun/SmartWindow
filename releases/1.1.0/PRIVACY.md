# 智慧窗隐私政策

**生效日期：2026 年 11 月 14 日**

智慧窗由 **Sendyun Technology Unit** 与原作者 **Mr.Dove** 提供。本隐私政策说明智慧窗如何处理与用户设备相关的信息。

## 1. 通知信息

在用户授权后，智慧窗通过 Windows 本地通知接口读取通知标题、正文、应用名称和时间信息，用于在屏幕顶部显示通知浮窗。

通知数据仅在本机处理，不会上传至 Sendyun 服务器，不会出售或提供给广告商及其他第三方。

## 2. 媒体信息

当用户开启音乐模式时，智慧窗通过 Windows 媒体会话接口读取当前播放状态、歌曲名称、歌手、专辑名称和专辑封面，用于显示顶部媒体窗口并提供播放控制。

媒体数据仅在本机处理，不会上传至 Sendyun 服务器。

## 3. 本地数据

智慧窗可能在用户设备的本地应用数据目录中保存：

- 通知、音乐模式、透明效果、窗口大小和语言等设置；
- 当前专辑封面缓存；
- 用于恢复系统通知横幅状态的本地备份；
- 程序错误日志；
- 用户主动开启开机自启动时使用的 Windows 启动项。

这些数据仅保存在用户设备中。用户可以通过删除 `%LOCALAPPDATA%\SmartWindow` 数据目录或卸载应用来清除相关数据。

## 4. 系统权限和系统设置

智慧窗可能使用以下 Windows 功能：

- 读取 Windows 应用通知；
- 读取 Windows 系统媒体会话；
- 调整应用通知横幅显示设置，以隐藏右下角原生横幅；
- 注册全局快捷键；
- 在用户主动开启时注册开机启动项。

正常退出时，智慧窗会尝试恢复此前修改的通知横幅设置。用户可以在智慧窗控制台或 Windows 系统设置中关闭相关功能。

## 5. 网络与数据共享

智慧窗不要求注册账号，不包含广告，不收集广告标识符，也不会主动将通知、媒体信息或播放历史上传到外部服务器。

当用户主动点击 GitHub 标志或反馈邮箱时，Windows 会调用默认浏览器或邮件应用。该外部应用的数据处理行为受对应第三方服务的隐私政策约束。

## 6. 数据出售和商业共享

Sendyun Technology Unit 不会出售、出租、交易或向广告商提供用户在智慧窗中处理的个人数据。

## 7. 数据保留与安全

本地设置、日志和缓存仅在实现本地功能所需的范围内保留，直至用户主动删除或卸载应用。

智慧窗不会专门收集儿童个人信息，也不会要求用户提交姓名、年龄、身份证件、联系方式或其他身份信息。

## 8. 政策更新

如果智慧窗的数据处理方式发生重大变化，本隐私政策会同步更新，并在项目仓库中发布新版本。
