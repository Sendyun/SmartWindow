# 智慧窗 Ver 1.1.0

本版本是智慧窗的完整体验升级，包含：

- 智慧窗移动、圆形拖拽、四边吸附与停靠位置记忆。
- 防遮挡鼠标穿透、任务栏避让、多显示器与 DPI 适配。
- 自适应帧率和复用 DIB 渲染，降低动画期间资源开销。
- 通知历史、应用过滤、全屏自动静默。
- 专辑封面异步加载、播放进度跳转、系统音量控制。
- 配置导入、导出与恢复默认。
- 后台健康检查、异常恢复与安全模式。

## 下载

- 安装程序：`SmartWindow-Setup-x64.exe`
- 便携版：`SmartWindow.exe`
- Microsoft Store MSIX：`SmartWindow_1.1.0.0_x64.msix`
- Partner Center 上传包：`SmartWindow_1.1.0.0_x64.msixupload`
- 完整源码：`SmartWindow-1.1.0-Source.zip`

安装器支持静默安装：

```powershell
.\SmartWindow-Setup-x64.exe /S
```

校验所有发布文件的 SHA-256，请参考 `SHA256SUMS.txt`。

## 系统要求

- Windows 11
- x64
- 无需管理员权限
