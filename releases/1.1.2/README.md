# 智慧窗 Ver 1.1.2

Ver 1.1.2 主要更新：

- 修复音乐播放时偶发无法弹出新通知的问题。
- 使用全新透明圆角正方形双 Logo。
- 控制台双 Logo 平滑切换，并同步切换品牌文字。
- 记录首次安装日期，升级不会清零。
- 控制中心和关于作者页面常驻显示安装天数。
- 点击安装天数可查看首次安装日期、星期、陪伴天数和版本。
- 长语言文案支持自动横向循环滚动。

## 下载

- 安装程序：`SmartWindow-Setup-x64.exe`
- 便携版：`SmartWindow.exe`
- Microsoft Store MSIX：`SmartWindow_1.1.2.0_x64.msix`
- Partner Center 上传包：`SmartWindow_1.1.2.0_x64.msixupload`
- 完整源码：`SmartWindow-1.1.2-Source.zip`

安装器支持静默安装：

```powershell
.\SmartWindow-Setup-x64.exe /S
```

校验所有发布文件的 SHA-256，请参考 `SHA256SUMS.txt`。

## 系统要求

- Windows 11
- x64
- 无需管理员权限
