# SmartWindow 1.0.1

## Microsoft Store package

- Installer: `SmartWindow-Setup-x64.exe`
- Architecture: `x64`
- Installer type: `EXE`
- Silent install parameters: `/S`
- Silent uninstall parameters: `/uninstall /S`

Direct download URL:

```text
https://raw.githubusercontent.com/Sendyun/SmartWindow/main/releases/1.0.1/SmartWindow-Setup-x64.exe
```

The installer installs SmartWindow for the current user without requiring administrator permissions.
